# HGTV Clean

面向 Android TV 和手机的视频客户端，支持遥控器与触屏操作。

项目使用 REA 分析原客户端的接口与运行流程，并根据分析结果重新实现协议。当前版本的接口请求、签名、扫码会话和视频数据源均由本项目 Java 源码实现，不依赖原客户端的 DEX 文件。

- 当前版本：**0.3.0 测试版**
- 应用包名：`com.hgtv.clean`
- 系统要求：Android 6.0 及以上

## 功能

- 漫剧、真人短剧、AI 分类推荐与关键词搜索。
- 作品详情、分集列表和播放结束后自动播放下一集。
- 480P、720P、1080P 清晰度选择，倍速播放和快进／快退。
- 上一集、下一集按钮，以及触屏上下滑动切集。
- 本机播放进度、观看历史和收藏。
- 可选的扫码登录、登录状态保存和账号连接验证。
- 播放控制栏无操作约 4 秒后收起，暂停、报错和打开菜单时保持显示。
- 无开屏广告、插屏广告或激励广告。

## 安装与使用

本地构建的安装包：`artifacts/HGTV-Clean-0.3.0-debug.apk`（构建产物不包含在源码仓库中）。

打开应用后，可通过推荐、分类或搜索找到作品，进入详情页选择分集播放。首次播放会自动初始化本机播放连接。

### 触屏操作

- 点击画面：显示或隐藏播放控件。
- 在画面中央上滑：下一集。
- 在画面中央下滑：上一集。
- 拖动进度条：调整播放位置。
- 使用底部按钮：选集、切换清晰度、调整倍速或快进／快退。

短距离滑动和偏横向滑动不会切集。标题、进度条和底部按钮区域保留各自的触摸操作；第一集与最后一集会限制越界切换。

### 遥控器操作

- 方向键与确认键：唤出控件、移动焦点和选择操作。
- 控件隐藏时，左右键快退／快进 10 秒。
- 播放／暂停键：控制播放状态。
- 上一项／下一项媒体键：切换分集。
- 返回键：退出播放或返回上一页。

### 扫码登录

登录为可选功能。在「设置 → 扫码登录」中获取二维码，使用官方 App 扫描并在手机上确认。

登录会话保存在本机，可在设置中验证账号连接。**播放进度、观看历史和收藏目前仅保存在本机，不支持跨设备云同步。**

## 开发与构建

接口请求、签名、扫码会话和视频数据源均由项目内 Java 源码实现。构建无需另一个 APK 或外部协议组件。

### 技术栈

- Java 17
- Android SDK 36
- Android Gradle Plugin 8.11.0
- Gradle 8.14.3
- AndroidX Media3 1.8.0

### 构建环境

Windows、Python 3.10+、JDK 17+，并正确设置 `JAVA_HOME`。

首次准备工具并构建：

```powershell
.\build.ps1 -SetupTools
```

常规构建：

```powershell
.\build.ps1
```

脚本会准备所需构建工具并生成调试签名安装包：

```text
artifacts/HGTV-Clean-0.3.0-debug.apk
```

使用已配置的 Gradle 8.14.3 执行构建与代码检查：

```powershell
gradle :app:assembleDebug :app:lintDebug
python scripts/check_boundaries.py
python scripts/test_signer.py
python scripts/check_media_protocol.py
```

Android 协议自测使用单独的测试包，默认只运行离线合成数据：

```powershell
gradle :app:assembleDebugAndroidTest
python scripts/check_android_protocol.py --adb <adb.exe路径> --serial <测试设备序列号>
```

添加 `--live` 可检查已安装客户端的推荐、搜索、分集、账号、视频源和二维码接口；此模式不会确认二维码、重新注册设备或上传本机记录。

## 连接说明

首次播放需要网络允许设备注册连接 `log.snssdk.com`。若初始化失败，请检查网络或域名过滤设置，再进入「设置 → 初始化本机播放连接」重试。

扫码登录、设备初始化失败或取消操作时，会保留已保存的本机资料。

## 验证范围

已在 Android 15 模拟器中验证横屏及 360dp 竖屏布局、视频播放、分集切换、滑动切集、清晰度切换、快进恢复、二维码获取与取消、既有登录恢复和账号连接验证。

为保留现有会话，本轮未重新注册设备或提交新的扫码确认。

当前提供调试签名测试包；真实电视与手机硬件、长期会话续期及全部作品的播放兼容性尚未完成验证。
